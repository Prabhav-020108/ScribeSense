# ScribeSense — Flutter App

## Structure
- lib/screens    — Home/Live Session, History, AI Coach, Settings
- lib/services   — BleService (S1.2), DbService (S1.3), AiService (S5)
- lib/models     — SensorSample, Session, Classification
- lib/providers  — session/connection state (S1.2, S2.2)
- lib/widgets    — gauges, charts, cards (S2+)

## Run
flutter pub get
flutter run
